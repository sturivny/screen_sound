# Changelog

## 1.2 — 2026-10-21

- English interface, error messages, permission descriptions and built-in AI templates.
- Generated macOS icon, ICNS resources and editable source/prompt assets.
- Stop saves locally and returns to idle without opening a blocking file dialog.
- Background export to Downloads with collision-safe names; original media remains.
- Latest completed recording restored from preferences and Recovery on launch.
- Completion-based AI file panels.

## 1.1 — 2026-10-19

- Opt-in OpenAI transcription and custom text tasks.
- Keychain credential storage, prompt templates and editable text results.
- Long-audio segmentation, transcript checkpoints, cancellation and mocked API tests.

## 1.0 — 2026-10-19

- Native SwiftUI recording app for macOS 15+ on Apple Silicon.
- Simultaneous system audio and microphone capture, optional screen video.
- Mixed M4A/MP4 output and synthetic media integration tests.
